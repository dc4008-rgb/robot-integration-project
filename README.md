# 机器人集成课程作业

本仓库用于提交机器人集成课程的实验代码、报告和验收记录。每个实验使用独立目录，
后续实验按编号依次新增，不与其他实验混放。

- [项目总结与展示](项目总结.md)

## 实验目录

| 实验 | 内容 | 状态 |
|---|---|---|
| [实验01：目标检测与识别](实验01_目标检测与识别/) | 数据采集、YOLO训练、Jetson部署、ROS 2发布与验收 | 实验优化完成，正式验收待通过 |

## 目录约定

```text
实验01_目标检测与识别/
实验02_待定/
实验03_待定/
```

每个实验目录独立保存：

- `README.md`：实验目标、环境、运行步骤和验收方法
- 阶段记录：已完成内容、实测结果和下一步任务
- 源代码与必要配置

原始数据集、模型权重、训练输出和视频不直接提交到 Git。需要归档时使用
GitHub Release、Git LFS 或课程指定存储，并在对应实验说明中记录下载地址与版本。
